# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 7.0.x   | :white_check_mark: |
| 6.1.x   | :white_check_mark: |
| < 6.0   | :x:                |

## Reporting a Vulnerability

We take the security of Gcalc seriously. If you discover a security vulnerability, please report it privately:

1. **Do not create a public GitHub issue.**
2. Send an email with details, reproduction steps, and potential impact to **krishkumarcodes@gmail.com**.
3. We will acknowledge receipt within 48 hours and work with you on a timely resolution before any public disclosure.
