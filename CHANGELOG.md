# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

## [5.0.0] - 2026-10-15
### Added
- Lookup-only physical constants tool with card expansion and favoriting.
- BackHandler support across all sub-screens for seamless Android system back gestures.

### Changed
- Maintenance and stability improvements across formula solvers.

## [5.0.0] - 2026-10-15
### Added
- Complete Apple-style liquid glass theme option.
- Custom accent color picker dialog with hue and saturation sliders.
- Support for wide zero key and left-handed calculator layouts.
- Real-time JSON data backup and restore engine.

### Fixed
- Fixed layout clipping and overlaps on compact screens (360px).
- Fixed fraction rendering to display genuine stacked fractions.

## [4.0.0] - 2026-10-14
### Changed
- Maintenance and stability improvements across mathematical parsing engines.
- Performance optimizations for Jetpack Compose layout recomposition.

## [3.0.0] - 2026-10-10
### Added
- Tools hub 2-column grid redesign with recent tools carousel and live search.
- Upgraded unit converter engine with expanded metric and imperial conversion factors.

### Changed
- Updated in-app version display and KRCODES attribution branding.

## [2.0.0] - 2026-09-28
### Added
- Notebook-style long division bracket visualization.
- History management with grouping by date, search, and tap-to-continue calculation.

### Fixed
- Improved calculation engine precision with BigDecimal scaling and clean number sanitization.

## [1.0.0] - 2026-09-15
### Added
- Initial release of Gcalc scientific and engineering calculator.
- Apple-inspired glassmorphic UI with dynamic Material accent palettes.
- Scientific drawer, trigonometry, logarithms, powers, and memory functions (`M+`, `M-`, `MR`, `MC`, `STO`, `RCL`).
- Offline PWA and Android package deployment.
